# Python Data Analyzer System

## Project Description
Python Data Analyzer ek menu-driven Python project che je 1D ane 2D data par vividh operations perform kare che. Aa project beginner students mate useful che ane tema Python na important concepts use karvama aavya che.

---

# Features

- Input 1D Data
- Input 2D Data
- Sample Dataset
- Basic Statistics
- Average Calculation
- Duplicate Values
- Unique Values
- *args and **kwargs
- Recursion
- Lambda Functions
- Global Variables
- Multiple Return Values
- 2D Matrix Display
- Sorting Operations
